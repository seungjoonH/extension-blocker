# 확장자 정책 샘플 안내

아래 샘플 파일로 일괄 입력과 `extignore` 동작을 확인할 수 있습니다.

## 일괄 입력

모드를 **일괄**로 바꾼 뒤, 쉼표로 구분해 입력합니다. 줄바꿈은 구분자가 아닙니다.

```
sh, dll, my-ext, tar.gz
```

- `sh`, `dll`, `tar.gz`처럼 형식이 맞으면 등록되거나, 고정 확장자면 활성화됩니다.
- `my-ext`처럼 허용되지 않는 문자가 하나라도 있으면 **전체**가 제출되지 않습니다.

## extignore 가져오기

가져오기는 파일을 고르는 즉시 줄 단위로 읽어 제출합니다.

```
exe
dll
sqlite-wal
```

| 샘플 | 결과 |
|---|---|
| `extignore.valid-200.txt` | 형식 OK, 커스텀 200개 한도 안 |
| `extignore.limit-201.txt` | 형식 OK, 커스텀 201개라 한도 초과 |
| `extignore.invalid-chars.txt` | 하이픈 등으로 전체 형식 오류 |

## extignore 내보내기

내보내기를 누르면 현재 **활성 고정 확장자**와 **커스텀 확장자**가 줄바꿈으로 이어진 `extignore.txt`가 내려갑니다.

예: 고정 `exe`가 활성이고 커스텀에 `dll`, `sh`가 있으면 파일 내용은 다음과 같습니다.

```
exe
dll
sh
```

## 초기화

초기화 → 확인을 누르면 커스텀은 모두 사라지고, 고정 확장자 체크는 모두 꺼집니다.

예: 커스텀 `dll`, `sh`와 고정 `exe`가 켜져 있어도, 초기화 후에는 커스텀 목록이 비고 `exe`도 꺼집니다. 업로드 최대 크기는 그대로입니다.
