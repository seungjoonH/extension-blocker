# 확장자 정책 샘플 안내

아래 샘플 파일을 활용해 커스텀 확장자 일괄 입력과 `extignore` 가져오기/내보내기 기능을 확인할 수 있습니다.

---

## 1. 일괄 입력

커스텀 확장자 영역에서 입력 모드를 **일괄**로 변경한 뒤, 확장자를 쉼표(`,`)로 구분해 입력합니다.

줄바꿈은 구분자로 사용하지 않습니다.

예시:

```
sh, dll, my-ext, tar.gz
```

입력 후 결과:

- `sh`, `dll`, `tar.gz`
  - 형식이 올바르면 등록됩니다.
  - 고정 확장자라면 해당 확장자가 활성화됩니다.

- `my-ext`
  - 허용되지 않는 문자가 포함되어 형식 오류로 처리됩니다.
  - 하나라도 오류가 있으면 전체 항목이 반영되지 않습니다.

---

## 2. extignore 가져오기

`extignore.txt` 파일을 선택하면 파일 내용을 줄 단위로 읽어 일괄 입력과 동일한 검증 과정을 거칩니다.

예시:

```
exe
dll
sqlite-wal
```

샘플 파일별 결과:

| 샘플 파일 | 결과 |
| --- | --- |
| `extignore.valid-200.txt` | 정상 형식이며 커스텀 확장자 200개까지 반영 가능 |
| `extignore.limit-201.txt` | 형식은 정상이나 커스텀 확장자 제한(200개)을 초과해 반영 실패 |
| `extignore.invalid-chars.txt` | 허용되지 않는 문자가 포함되어 전체 반영 실패 |

---

## 3. extignore 내보내기

내보내기를 실행하면 현재 활성화된 확장자 정책을 `extignore.txt` 파일로 내려받을 수 있습니다.

파일 내용은 다음 순서로 생성됩니다.

1. 활성화된 고정 확장자
2. 커스텀 확장자

모든 항목은 한 줄에 하나씩 작성됩니다.

예시:

현재 상태:
- 고정 확장자: `exe` 활성화
- 커스텀 확장자: `dll`, `sh`

내보내기 결과:

```
exe
dll
sh
```

---

## 4. 초기화

초기화 버튼을 누르면 확인 후 확장자 정책을 기본 상태로 되돌립니다.

초기화 대상:

- 등록된 커스텀 확장자 전체 삭제
- 활성화된 고정 확장자 전체 비활성화

초기화 대상이 아닌 항목:

- 업로드 최대 크기 설정 유지

예시:

초기 상태:

```
고정 확장자: exe 활성화
커스텀 확장자: dll, sh
업로드 최대 크기: 10MB
```

초기화 후:

```
고정 확장자: 없음
커스텀 확장자: 없음
업로드 최대 크기: 10MB 유지
```
